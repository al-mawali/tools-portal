Change log

DiffDesk · Developed by Habib AlMawali

v1.0.0 – 19 Nov 2026 · Initial release

  • Side-by-side text compare with aligned rows and line numbers
  • Inline highlighting of changed characters inside modified lines
  • Sync scroll on/off, differences-only view with context
  • Ignore whitespace, case and blank lines options
  • Move changes per block (left→right / right→left) or all at once
  • Previous/next difference navigation (Alt+↑ / Alt+↓)
  • Open files or drag & drop; swap sides; edit text directly
  • Export summary report (HTML/TXT), save left/right files, copy
  • Dark / light theme; works fully offline from a single file
