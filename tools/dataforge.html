Version history

Developed by Habib AlMawali

v1.4.0 22 Nov 2026 · Export and edit update

  • Excel (.xlsx) export with a styled, frozen header row, auto-filter, column widths, real numbers, booleans and dates; it replaces the old .xls export
  • Charts from column statistics: click a column in the Stats tab for a histogram or top-values bar chart, or chart a sum or average by category; save as SVG or PNG
  • Editable recorded steps: edit ✎, reorder ‹ ›, or remove ✕ any step and the table is rebuilt from the loaded data. Cell edits, header renames, added rows and columns are now recorded too

v1.3.0 22 Nov 2026 · Insight update

  • Excel import: open .xlsx and .xlsm files (also in multi-file merge), pick a sheet, dates are converted to YYYY-MM-DD
  • Saved transform steps: every clean-up you apply is recorded, then saved as a named recipe and replayed on new data; recipes can be exported and imported
  • Column statistics tab: type, filled and empty counts, unique values, min, max, mean, median, sum, standard deviation and most common values

v1.2.0 22 Nov 2026 · Organise update

  • Column reordering: drag the ⠿ handle, use the ‹ › buttons (works on touch screens), or sort columns A–Z
  • Multi-file merge: drop or select several files, or add files to the current table; append rows by column name or join side by side, with an optional source_file column
  • Saved presets for import and export settings, stored in your browser, with export and import to share them between machines

v1.1.0 22 Nov 2026 · Transform update

  • Find & replace across all columns or one column, with regex and match-case options
  • Column type conversion: number, integer, boolean, date (YYYY-MM-DD), text, upper/lower/title case, trim
  • JSON path extraction such as $.data.users[*].name or items[0].tags, with a reset to the original input
  • Conversion and replace report how many cells changed or could not be converted

v1.0.0 22 Nov 2026 · Initial release

  • Import CSV, TSV, JSON, NDJSON, Markdown and HTML tables by paste, file or drag & drop
  • Export JSON, NDJSON, CSV, TSV, Markdown, HTML, SQL, XML, YAML and Excel (.xls)
  • JSON prettify, minify and key sorting; nested objects are flattened into dotted columns
  • Editable table with sort, filter, add/remove rows and columns, undo
  • Tools: trim, drop empty rows, remove duplicates, transpose, clean headers
  • Auto-detects format and delimiter; light and dark themes; fully offline, no external requests

Next Planned

  • Multi-sheet .xlsx export, line and pie charts, sharing recipe bundles
