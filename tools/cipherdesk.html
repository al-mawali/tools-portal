Change log

v Latest 22 Nov 2026

  • Initial release: fully offline, single-file, zero dependencies
  • Text encryption: AES-256/128-GCM, AES-256-CBC, AES-256-CTR with PBKDF2
  • File encryption with drag & drop, self-describing .cdesk format
  • RSA-OAEP key generation, encryption and decryption (PEM import/export)
  • SHA-1/256/384/512 hashes, HMAC, file hashing and hash verification
  • Base64, Base64URL, Hex, Binary and URL encoders
  • Classic ciphers: Caesar, ROT13, Atbash, Vigenère, XOR
  • Password, key and UUID generators with entropy meter
  • Responsive layout, dark/light theme, strict no-network policy
