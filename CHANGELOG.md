# Changelog

## [1.1.0] - 2026-11-18

### New
- Tool flags: Public, Private, Open Source, Internal, Beta, New, Coming Soon, Maintenance and Deprecated.
- Private tools show an access-request dialog with criteria and contact details.
- Filter tools by flag, plus an optional "View source" link for open-source tools.

### Improved
- ACE Dashboard is now flagged as Private.

## [1.0.0] - 2026-11-17

### New
- Initial release of the tools portal.
- Added ACE Dashboard, Markdown Converter and Release Snippets cards.
- Foldable tool descriptions, search, and light/dark theme.
- Version label and changelog.
